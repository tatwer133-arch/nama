# سيجا رويال 👑 — Seega Royale

موقع عربي RTL للموبايل يشبه تطبيق ألعاب اجتماعية من ناحية التجربة (لكن ليس نسخة من تصميم أو أصول أو علامة أي تطبيق آخر). يحوّل لعبة السيجا المصرية إلى غرف لعب على الإنترنت، شات، صوت، أصدقاء، عملات افتراضية، ومكافآت.

## الموجود فعليًا في النسخة

- **محرك سيجا كامل**: لوحة 5×5، 12 حجر لكل لاعب، رصّ حجرين بالدور مع استثناء الوسط، حركة أفقية ورأسية، أكل بالتطويق، مناعة الوسط، أكل متتالٍ، تمرير اللعب عند الحبس، إنهاء عند الفوز أو التعادل. اختلافات القواعد الشعبية قابلة للتطوير.
- **غرف لاعبين مباشرة**: غرفة خاصة بكود 6 حروف ورابط دعوة، غرفة عامة، مطابقة سريعة، وغرف VIP باشتراك عملات افتراضية داخل اللعبة (بدون فلوس حقيقية).
- **روبوت كمبيوتر** للتجربة منفردًا مع خطوات آلية على السيرفر.
- **حسابات**: ضيف، إيميل وكلمة مرور (scrypt مشفر)، وطرق OAuth جوجل وفيسبوك تعمل بعد إدخال مفاتيح المطور الرسمية.
- **شات**: شات الغرفة، شات عام، أصدقاء، رسائل مباشرة مع حدود إرسال أساسية.
- **محادثة صوتية**: WebRTC مُفعَّل بالضغط على الميكروفون + إشارات عبر WebSocket. تحتاج HTTPS وإذن ميكروفون. قد تحتاج TURN للتواصل بين شبكات مختلفة؛ لم يتم إجراء اختبار اتصال صوتي حقيقي عبر شبكتين.
- **اقتصاد افتراضي**: 2500 كوين و75 جوهرة جديدة لكل لاعب، هدية يومية، مكافآت الفوز، متجر سكنات، وتخصيص الأفاتار. لا يوجد شحن، دفع، مراهنة، تبديل أو سحب نقدي.
- **واجهة تطبيق**: موبايل-أول، PWA قابلة للإضافة للشاشة الرئيسية، صفحات اللوبي/الغرف/المتجر/الأصدقاء/الملف الشخصي.

## التشغيل المحلي

تحتاج Node.js v22.13 أو أحدث فقط، **لا توجد مكتبات خارجية تحتاج تثبيت**.

```bash
export SESSION_SECRET="replace-with-a-long-random-secret"
export BASE_URL="http://localhost:3000"
npm start
```

افتح `http://localhost:3000` من متصفحك.

### الاختبارات

```bash
npm test
```

الاختبارات تغطي محرك السيجا، الحسابات بالإيميل، الكوينز والمكافآت، المتجر، الغرف، الأصدقاء، واستجابة صفحات الموقع. جرى اختبار WebSocket الأساسي ورسائل الغرفة وتحريك حجر فعلي بين عميلين محليًا. لا تُعد هذه اختبارات تحميل أو أمان أو اتصال صوتي بين أجهزة خارجية.

## إعداد النشر

1. أنشئ خدمة **Node Web Service** عامة في Render أو مزود يدعم سيرفر Node واتصالات WebSocket مستمرة. أمر التشغيل `npm start`، وبناء المشروع لا يحتاج `npm install`.
2. اضبط `SESSION_SECRET` لقيمة طويلة عشوائية وثابتة، و`BASE_URL` للدومين النهائي، و`NODE_ENV=production`.
3. اضبط Node 22 أو أحدث. المشروع يستخدم `node:sqlite` المدمج (تجريبي في بعض إصدارات Node).
4. **مهم جدًا: قاعدة البيانات موجودة في `DATA_DIR/seega.db`**. للاستمرار الحقيقي بين إعادة التشغيل، تحتاج تخزينًا دائمًا (`DATA_DIR=/var/data` مع قرص دائم) أو نقل التخزين إلى PostgreSQL. استضافة Render المجانية ملفاتها مؤقتة، ولذلك لا تصلح بعدُ لحفظ حسابات اللاعبين والكوينز بصورة موثوقة.
5. الغرف واللعب المباشر محفوظة في ذاكرة سيرفر واحد. النشر على أكثر من نسخة يتطلب Redis/مزامنة غرفة مركزية، وربط إعادة الاتصال باستئناف المباراة بعد سقوط السيرفر.
6. الصوت يحتاج HTTPS واختبار TURN. تقدر تضيف خوادم STUN/TURN عبر `ICE_SERVERS_JSON` مثل `[ {"urls":"turn:turn.example.com","username":"...","credential":"..."} ]`. لا تضع مفاتيح حساسة داخل الملفات العامة.

### تسجيل جوجل

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- Authorized redirect: `https://YOUR-DOMAIN/api/auth/google/callback`

### تسجيل فيسبوك

- `FACEBOOK_APP_ID`
- `FACEBOOK_APP_SECRET`
- Valid OAuth redirect: `https://YOUR-DOMAIN/api/auth/facebook/callback`

كلاهما يحتاج إعداد تطبيق المطور والموافقة على إعدادات OAuth وسياسات استخدام البيانات.
