# سيجا رويال V11 — تحسين تسجيل الدخول مع Firebase

- نفس الجرافيك والألعاب والتواصل الموجودة في V10.
- إصلاح منع فتح اللعبة إذا نجح تسجيل جوجل لكن Firestore لم يُفعَّل أو رفض مزامنة الملف الشخصي؛ يظل الدخول متاحًا محليًا مع تنبيه صريح بأن المزامنة غير متاحة.
- رسائل أكثر وضوحًا لمشكلات OAuth: نافذة منبثقة محظورة، دومين غير مصرح، طريقة دخول غير مفعّلة، متصفح داخلي غير مدعوم، انقطاع الاتصال.
- إعادة محاولة استيراد SDK بعد فشل مؤقت بدل الاحتفاظ بوعد Promise مرفوض.
- ترقيم ملفات الكاش V11 حتى تصل التعديلات على الموبايل.
- اختبارات محلية: 60/60 نجحت (ليست اختبارًا على خدمات Firebase الفعلية).

## الحدود الحالية
لا يمكن تفعيل Firestore أو نشر قواعده عبر `firebaseConfig` العام. يتطلب ذلك صلاحية إدارة على مشروع Firebase `seega-royal`، وإنشاء قاعدة بيانات default ونشر `firestore.rules`، ثم التحقق من خدمة Authentication ودومين `seega-royale-eg.vercel.app`.

مزامنة البروفايل والأصدقاء والـID لا تُعتبر جاهزة حتى اختبارها بين جهازين. رصيد الكوينز والجواهر ونتائج المباريات لا تزال محفوظة محليًا، وغرف اللعب P2P تجريبية. تسجيل فيسبوك يحتاج تهيئة Meta منفصلة.
