# سيجا رويال V4 — نسخة موبايل مجانية (تجريبية)

**الرابط:** https://seega-royale-eg.vercel.app

## الذي يعمل الآن
- 6 ألعاب قابلة للعب محلياً: السيجا المصرية **5×5** (12 حجر)، **7×7** (24 حجر)، **9×9** (40 حجر)، الداما الأمريكية **8×8**، الداما الروسية **8×8**، والداما الصينية **121 حفرة/10 كرات لكل طرف**.
- محركات مختلفة لقواعد كل لعبة؛ الصينية سباق مع قفز بلا أكل، والداما الأمريكية قفز مع أكل إجباري وتتويج الملك، والروسية ملك طائر وأكل للخلف.
- اللعب ضد روبوت محلي أو لاعبان على جهاز واحد.
- واجهة عربية للأجهزة المحمولة، وتلبيس بصري ثلاثي الأبعاد باستخدام CSS transforms والظلال والخامات (ليس محرك Three.js أو مجسمات WebGL حقيقية)، وزر 2D/3D.
- زر دردشة عائم لفتح/قفل محادثة الجولة من غير سكرول إلى أسفل، وهدايا إلى أفاتار الخصم عند النقر عليه.
- موسيقى خلفية أصلية مؤلّفة آلياً باستخدام Web Audio مع زر للإيقاف والتشغيل، ومؤثرات مختلفة للتحريك والأكل والتنبيه والفوز والهدايا.
- غرف أونلاين **تجريبية**: ينشئ لاعب غرفة برمز من 6 حروف ويشارك اللينك، وينضم لاعب من جهاز آخر؛ نقل الحركات والشات والهدايا من جهاز لجهاز عبر WebRTC DataChannel باستخدام PeerJS Cloud المجاني لخدمة الإشارة. صاحب الغرفة هو المرجع لقرارات اللعبة. فيه فويس تجريبي عبر WebRTC إذا كانت الشبكة تسمح.
- قائمة ألوان مختلفة، بروفايل بصور الجاليري، عملات وجواهر هدايا **تجريبية** على الجهاز، دوري وتاريخ لعب **محلي**.

## قيود يجب فهمها قبل الاعتماد على اللعبة
- اتصال الأونلاين بتقنية Peer-to-Peer **مش مضمون على كل شبكات المحمول/الراوتر** وقد يحتاج TURN relay أو خادم إشارة مخصص. PeerJS Cloud خدمة مجانية مشتركة وليست بنية إنتاجية تضمن uptime أو matchmaking.
- لابد أن صاحب الغرفة يسيب صفحته مفتوحة؛ لو قفلها تتوقف الغرفة. لا توجد قائمة غرف عامة أو بحث آلي عن منافس.
- إن بعض شبكات WebRTC تكشف IP الطرف الآخر مباشرة بطبيعة الاتصال؛ تفعيل TURN موثوق مهم قبل إطلاق اجتماعي عام.
- لا يوجد تسجيل آمن عبر جوجل/فيسبوك/الإيميل ولا قاعدة بيانات مركزية؛ الـIDs والصداقة ولوحات الشرف والدوريات والعملات **محلية على هذا الجهاز** وغير موثقة بين اللاعبين. لا يمكن اعتبار الجوائز تنافسية أو ذات قيمة مالية.
- مافيش anti-cheat على خادم مستقل، لذلك الغرف التجريبية مخصصة للأصدقاء فقط.
- الأونلاين والفويس يحتاجان تجربة على موبايلين وشبكتين حقيقيتين بعد النشر؛ الاختبارات الحالية محاكاة عميلين في Node وليست اختباراً خارجياً لPeerJS Cloud.
- مؤثرات وألحان Web Audio مصطنعة أصلية، مش ملفات موسيقى تجارية.

## التشغيل والاختبار
```bash
cd seega-v4
python -m http.server 8080 --directory public
node --test tests.mjs tests-v4.mjs tests-online.mjs
```
حفظ الملف المحلي يستعمل نفس مفتاح النسخ الأقدم `seega_royale_demo_v2` للحفاظ على حسابات اللاعبين التجريبية.
