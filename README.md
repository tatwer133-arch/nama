# سيجا رويال — النسخة المجانية V2

رابط الموقع عند النشر على Vercel: https://seega-royale-eg.vercel.app

## مزايا قابلة للتشغيل
- سيجا مصرية 5×5 (12 حجر لكل طرف) و7×7 (24 حجر لكل طرف).
- اللعب ضد الكمبيوتر، أو لاعبان على نفس الهاتف.
- أربعة ألوان مختلفة (أحمر، أزرق، أصفر، أخضر) تمنع تضارب اللون بين اللاعبين.
- تأثير بصري تدريجي عند أكل الحجر، وعدّاد الأكل في الجولة وعلى الملف الشخصي.
- ثماني هدايا تفاعلية تعمل محليًا وتستهلك كوينز تجريبية.
- هوية مستقرة بصيغة SG-XXXXXXXXXX؛ حفظ معرّفات الأصدقاء على جهاز واحد (بدون طلبات صداقة حقيقية).
- لوحة شرف محلية، وأربعة مستويات في دوريات أسبوعية محلية مع جوائز افتراضية وانتقال بين المستويات.
- تغيير الأفاتار أو صورة البروفايل من الجاليري؛ ضغط الصورة إلى 256×256 JPEG والتخزين المحلي.
- حفظ نسخة الحساب القديم من localStorage (المفتاح seega_royale_demo_v2) مع ترقية البيانات دون مسح رصيدها.

## قيود واضحة
هذه نسخة مجانية **محلية فقط**: لا يوجد سيرفر دائم أو قاعدة بيانات مركزية. لا تعمل الغرف العابرة للأجهزة، ولا الصداقات/المراسلة الحقيقية، ولا الترتيب العالمي الحقيقي، ولا الصوت المباشر، ولا تسجيل Google/Facebook أو البريد. لا يُسمح بالعملات المدفوعة أو الجوائز النقدية. كل رقم وتعامل على هذا الإصدار قابل للتغيير محليًا، فلا يصلح كمنافسة عامة عادلة. يُوصى بربط هوية وحركات لعبة موثقة وقاعدة بيانات مشتركة لخدمات الأونلاين الفعلية.

## تشغيل واختبار
يمكن فتح `public/index.html` من أي خادم ملفات ثابت يدعم MIME للوحدات JavaScript. لن تعمل import module من file:// بلا خادم.

```bash
cd seega-free
python -m http.server 8000 --directory public
node --test tests.mjs
node api_test.mjs
node html_test.mjs
```

مصدر اللعبة على GitHub فرع `seega-royale` للنسخة الأصلية متعددة اللاعبين، وملفات هذا الإصدار V2 يمكن نشرها على Vercel مباشرة.
